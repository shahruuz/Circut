┌─────────────────────────────────────────────────────────────────────────────┐
│ STEP 1: PREPARE YOUR COMPUTER                                               │
├─────────────────────────────────────────────────────────────────────────────┤
│ • Install Git: https://git-scm.com                                          │
│ • Install Node.js: https://nodejs.org (18.x or 20.x LTS)                   │
│ • Extract cricut-shop folder                                               │
│ • Open Terminal/Command Prompt in cricut-shop folder                       │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ STEP 2: TEST LOCALLY                                                         │
├─────────────────────────────────────────────────────────────────────────────┤
│ $ npm install                                                               │
│ $ npm run dev                                                               │
│ → Visit: http://localhost:3000                                             │
│ → Stop: Press Ctrl+C                                                        │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ STEP 3: CUSTOMIZE (OPTIONAL)                                                 │
├─────────────────────────────────────────────────────────────────────────────┤
│ Edit these files:                                                           │
│ • src/lib/products.js → Update products                                    │
│ • src/components/Footer.js → Update contact info                           │
│ • tailwind.config.js → Change colors                                       │
│ • public/images/ → Add your images                                         │
│                                                                             │
│ Then restart server:                                                        │
│ $ npm run dev                                                               │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ STEP 4: UPLOAD TO GITHUB                                                     │
├─────────────────────────────────────────────────────────────────────────────┤
│ 1. Create GitHub account: https://github.com/signup                        │
│                                                                             │
│ 2. Create personal token:                                                   │
│    https://github.com/settings/tokens/new                                  │
│    - Check: repo, workflow                                                  │
│    - Copy token somewhere safe!                                            │
│                                                                             │
│ 3. Initialize Git:                                                          │
│    $ git init                                                               │
│    $ git config user.name "Your Name"                                      │
│    $ git config user.email "your@email.com"                                │
│                                                                             │
│ 4. Add files:                                                               │
│    $ git add .                                                              │
│    $ git commit -m "Initial commit: CutSheet Co. store"                     │
│                                                                             │
│ 5. Create repo on GitHub:                                                   │
│    https://github.com/new                                                   │
│    - Name: cricut-shop                                                      │
│    - Public                                                                 │
│    - Create repository                                                      │
│                                                                             │
│ 6. Push to GitHub:                                                          │
│    $ git remote add origin https://github.com/YOUR-NAME/cricut-shop.git   │
│    $ git branch -M main                                                     │
│    $ git push -u origin main                                                │
│    → When prompted for password: Use your personal token!                  │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ STEP 5: DEPLOY TO VERCEL (Easiest!)                                          │
├─────────────────────────────────────────────────────────────────────────────┤
│ 1. Go to: https://vercel.com/signup                                        │
│ 2. Click: "Continue with GitHub"                                           │
│ 3. Authorize Vercel                                                        │
│ 4. Click: "Add New" → "Project"                                            │
│ 5. Select: cricut-shop repository                                          │
│ 6. Click: "Import"                                                         │
│ 7. Click: "Deploy"                                                         │
│ 8. Wait 2-3 minutes...                                                      │
│ 9. Your site is LIVE! 🎉                                                   │
│    → URL: https://cricut-shop.vercel.app                                   │
│    → Or your custom domain (see STEP 6)                                    │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ STEP 6: ADD CUSTOM DOMAIN (OPTIONAL)                                         │
├─────────────────────────────────────────────────────────────────────────────┤
│ 1. Buy domain:                                                              │
│    • Namecheap: $0.88/year → namecheap.com                                 │
│    • GoDaddy: $1/year → godaddy.com                                        │
│                                                                             │
│ 2. In Vercel:                                                               │
│    → Settings → Domains → Add Domain                                       │
│    → Enter your domain                                                      │
│    → Copy DNS records shown                                                │
│                                                                             │
│ 3. In Domain Registrar:                                                     │
│    → Manage Domain → Advanced DNS                                          │
│    → Add CNAME record as shown in Vercel                                   │
│    → Wait 24-48 hours for propagation                                      │
│                                                                             │
│ 4. Verify:                                                                  │
│    → Visit: https://www.yourdomain.com                                     │
└─────────────────────────────────────────────────────────────────────────────┘

├─────────────────────────────────────────────────────────────────────────────┤
